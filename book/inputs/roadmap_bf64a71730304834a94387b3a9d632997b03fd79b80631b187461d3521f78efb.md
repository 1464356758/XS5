# 《离婚前夜，账本里多了一个死人》长篇路线 v1

> 100章 × 约9000汉字 = 约90万汉字；章节数字是作者规划，不是已经采用或发布的进度。可在每章采用前动态调配，但不得通过无效重复凑字数。

## 五幕、五种主要对抗

### 第一幕 1—20章｜离婚协议与死者署名（18万汉字）

林见微从熟悉的生活中被剥离：丈夫告知公司不再需要她，同时送来离婚财产清单。她发现一份上游技术报告仍有七年前已故匠人的最新签名。目标是守住合法访问权、追溯文件来源与完成自保；障碍是供货商拒绝配合、前夫隐瞒债务和自己多年丢失的工作声誉。主要盟友梁予书，专业分歧来自贺寻。第10章核实报告复用，第20章取得第一份合法可公示的矛盾证据，同时失去婚姻/合伙安全网，明确未来只能独立谋生。不可用死亡署名直接推出全链犯罪。

### 第二幕 21—40章｜旧工厂的活账（18万汉字）

主角与梁予书接下受损制造商的成本核查，解决一系列具体问题：重复发票、应付账款、质检外包与劳务欠款。每个案子都能局部完成，但证据指向一个供应商网络。第30章发现旧工厂曾为七年前出事项目供货，第40章有人为保工作主动隐瞒，女主必须在保护员工与披露风险间选择，团队付出实际损失。对抗从家庭走向企业系统。

### 第三幕 41—60章｜围城供应链（18万汉字）

地方旧区改造进入关键节点，资金链条和签章权层层嵌套。傅芸尝试报道、贺寻提出专业反证，女主遭遇“把舆情当证据”的诱惑。第50章发现恩师沈望山参与过关键审批设计，但不确定其是否主犯；第60章女主过去一次未核签字被公开，职业信誉跌至最低点。此幕让主角从“查别人”变为“先查自己”。

### 第四幕 61—80章｜投资人的影子（18万汉字）

调查进入融资担保与跨企业重组。事实并非简单的公司套壳，更有当年管理失误、商誉保护和脆弱企业求生。第70章证明多个对立阵营都不愿真相公开，第80章女主拒绝以私下交易掩盖历史责任，失去救急资金与关键盟友。对抗从寻证走向公共责任与个人代价。

### 第五幕 81—100章｜为真实签名（18万汉字）

林见微与各方合法推动证据核查和公众沟通，旧案相关责任分级明确，既不以舆论裁判替代程序，也不靠最后一张U盘自动洗白。第90章面对证据缺口决定公开自身疏失，第96章她在关键决定上选择保全更多普通人的权益而不是追求绝对胜利。第100章以完成必要纠偏、被害者获得发声机会、女主建立独立调查团队为终点，情感线落在相互尊重的协作，而非前夫悔恨。

## 五个关键转折（因果检查用）

1. 第10章：签署日期冲突被独立验证，但纸面证据不足以定罪 → 必须再查授权源。
2. 第20章：发现报告在两个项目重复出现 → 离婚财产/合伙人权益与业务调查完全分叉。
3. 第40章：证人不愿公开，主角尊重撤回 → 从公开揭发调整为保护当事人和补足证据。
4. 第60章：女主自己签署过不完整变更表 → 主角从调查者转为利益相关者，信誉受损。
5. 第80章：可以用沉默换团队生存 → 拒绝秘密交易、承担团队财政代价。

## 第1—5章近期场景计划（未写成正文）

**第1章《签给死人的报告》**：开场周祈安把离婚协议压在家庭餐桌，称林见微离开公司是彼此体面。她收到授权邮箱的例行对账，看到“冯启怀，2026年度巡检顾问签收”，但曾经参加过冯启怀葬礼。女主第一次采取行动：保存合法持有的对账邮件及原始头信息，并核对公开纪念公告。章末：同一报告还被用于申请一项新工程付款。悬念要和现实损失绑定，不借违法入侵。

**第2章《离婚不是注销权限》**：林见微核查股东与财务岗位文件，确认自己的合法查阅边界，与周祈安对峙不作孤注一掷的威胁。前夫试图把婚姻财产争议混成“她精神不稳定”。章末：供应商一笔正常付款背后出现同一合同编号的重复版本。

**第3章《一张没有退路的借条》**：林见微联系梁予书求证公司旧采购流程，梁因裁员赔偿不愿配合。女主必须付出信誉担保与调查时间，而不是白拿证据。章末：梁指出伪造签名并非最危险之处，真正的问题是交货数量。

**第4章《验收单上的第三个人》**：从招投标与公开资料交叉核对三个签署者，一名实地验收人员告诉女主“那天没有项目施工”。贺寻提出可能存在合法变更，反驳她过早定论。章末：变更申请的日期晚于据称完成施工的日期。

**第5章《烧掉的旧厂房》**：女主找到冯秋棠，遭遇拒绝透露父亲私人资料。她选择尊重隐私，转查公开工商与建筑档案，发现七年前旧厂事故记录中也有相同合同号的编号规律。章末：有人向林见微提出“撤回调查，就替她付清离婚债务”。拒绝后损失实际资金来源，进入下一段主动调查。

## 连载的具体管控

- 一章必须有一个无法被一句解释取代的行动决定，一次关系或资源的实际变化，一条回收或新增的可核验证据。
- 每5章采用前回看悬念、角色知识边界、证明链与行为代价，每20章改变目标层次。
- 第一章不提前“剧透整条阴谋”，各幕事实发现按证据顺序记录至章后材料；与近期情节相似的商业悬疑文必须检查原创差异。
- 关键法律与工程事实先查可靠资料；描绘诈骗犯罪只写侦查与伦理层面，不输出可复制的犯罪教程。
- 与平台相关的AI内容规则仍未核实，不将小说自动提交点众或自动签约。
